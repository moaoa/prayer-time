Plan · Audio Generation

Procedural Prayer Sounds with Python

A plan to synthesize adhan-inspired alert sounds for all five prayers (fajer, dhuhr, asr, maghrib, isha) entirely in Python — producing several distinct variations to audition, so you can approve the one you like before it ships into the app.

1. Goal

Replace / supplement the current placeholder files in src-tauri/sounds/ with cleanly synthesized alert tones generated by a Python script. The script produces multiple complete sound packs (variations). You listen, pick one, and we copy that pack into the app's sound folder.

Honest scope note: Pure Python DSP cannot reproduce a real human adhan (that requires a vocal recording or singing-voice synthesis). These variations are adhan-inspired tonal / melodic chimes — calm, recognizable call-to-prayer alerts. If you actually want a recorded muezzin voice, that's a different (non-generative) path and I'll flag it instead.

2. How the app consumes sounds today

The Rust backend resolves one file per prayer and plays it through rodio. Our generated files just need to land in the right folder with the right names.

3. Tech stack

Synthesis

numpy for oscillators, envelopes, FM, additive partials, noise & filtering.

File output

soundfile (or scipy.io.wavfile) writes 44.1 kHz WAV.

MP3 encode

ffmpeg via subprocess (or pydub) converts WAV → MP3.

Dependencies kept minimal & offline: pip install numpy soundfile + system ffmpeg. No external APIs, no audio assets downloaded.

4. Generation pipeline

Each prayer sound is built from the same parametric pipeline; the parameters are what differ between variations and between prayers.

fade in/out"] NORM --> WAV["WAV 44.1kHz"] WAV --> MP3["ffmpeg → MP3 (192 kbps)"] MP3 --> OUT["sounds_generated/{variation}/{prayer}.mp3"]

5. The variations

I'll generate four complete packs (each pack = all 5 prayer sounds in a consistent style). You can approve one pack, or mix-and-match per prayer.

Variation A

Gentle Chime (Bells)

Soft glockenspiel/bell tones via additive synthesis with slightly inharmonic partials and a long, shimmering decay. Calm and modern.

Feel: serene, unobtrusive · Best for: a soft household alert.

Variation B

Maqam Melody (Reed / Ney)

A short melodic phrase in a traditional adhan scale (Hijaz / Bayati), using filtered FM to emulate a ney reed flute, with gentle vibrato. The most "call-to-prayer" in character.

Feel: traditional, expressive · Best for: an authentic mood.

Variation C

Warm Gong / Singing Bowl

A low, warm gong strike with rich overtones and a meditative ring-out. Deep and grounding.

Feel: meditative, weighty · Best for: night prayers (isha, fajer).

Variation D

Modern Notification (Marimba)

Clean plucked / marimba arpeggio — a pleasant, concise desktop-notification style ping.

Feel: crisp, lightweight · Best for: minimal distraction.
