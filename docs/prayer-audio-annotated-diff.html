Virtual device filter — double-play fix

On Linux/PipeWire, CPAL often lists Monitor of … loopback sinks alongside real speakers. Multi-speaker mode was playing on both, causing the adhan to be heard twice. is_physical_output() excludes monitor/loopback/null/dummy names before playback and in the Settings device list.

src-tauri/src/audio_output.rs · src/views/SettingsView.vue
--- src-tauri/src/audio_output.rs
+fn is_physical_output(name: &str) -> bool {
+    let n = name.to_ascii_lowercase();
+    !n.contains("monitor") && !n.contains("loopback")
+        && !n.contains("null") && !n.contains("dummy")
+}
 fn collect_output_devices() {
+    .filter(|d| d.name().map(|n| is_physical_output(&n)).unwrap_or(false))
